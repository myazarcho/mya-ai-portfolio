# Rainfall Prediction Classifier

A machine learning classification project for predicting rainfall using historical weather data.

## Project Workflow
- Data cleaning
- Feature engineering
- Train/test split
- Preprocessing pipeline
- Random Forest
- Logistic Regression
- Cross-validation
- Model evaluation

## Evaluation
The models are evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

## Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
